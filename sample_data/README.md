# 재현용 샘플 데이터

《AI로 찾는 오늘의 대장주 따라하기》 4장 이후 실습을 직접 수집 없이 재현하기 위한 데이터입니다. 책의 3장 파이프라인(`ch03_pipeline`)으로 필자가 수집한 데이터의 일부입니다.

```bash
python -m ch03_pipeline.load_sample
```

## 파일

| 파일 | 내용 | 행 수 | 기간 |
|---|---|---|---|
| `stock_master.parquet` | KOSPI·KOSDAQ 종목 마스터 (2026-10-21 기준) | 4,403 | — |
| `daily_bars.parquet` | 유니버스(주권 중 SPAC 제외) 2,648종목 일봉 | 664,374 | 2025-10-01 ~ 2026-10-21 |
| `minute_bars.parquet` | 날짜별 정규장 거래대금 상위 100종목의 1분봉 | 2,273,944 | 2026-07-23 ~ 2026-10-21 (60거래일) |

- 시세 출처: 한국투자증권 Open API (KRX 시세, 시장 구분 `J`)
- 열 구성은 `ch03_pipeline/db.py`의 테이블 정의와 같습니다
- 분봉 종목 선정: 그날 수집한 거래대금 상위 300종목 중, 정규장 분봉 누적 거래대금 상위 100종목

## 알아 둘 한계

- **선택 편향**: 분봉 대상은 장 마감 후의 거래대금으로 골랐습니다. 장중 판단을 재현할 때는 책 03-4의 규칙을 지키세요
- **생존 편향**: 종목 마스터와 일봉은 2026-10-21에 상장된 종목만 담고 있습니다
- **일봉 거래대금**: 정규장 밖 대량매매가 포함되어 있습니다 (책 03-4)
- **수정주가**: 일봉은 수정주가(`FID_ORG_ADJ_PRC=0`), 분봉은 API가 주는 값 그대로입니다

## 이용 안내

이 데이터는 책의 실습을 위한 연구·교육 목적으로 제공합니다. 투자 판단의 근거로 쓰지 마세요. 시세 데이터의 정확성을 보장하지 않으며, 최신 시세나 상업적 이용이 필요하면 한국투자증권 Open API 등 공식 경로로 직접 수집하세요.
